## 1. Introduction

Huduma Platform is a multi-category service marketplace designed for Kenya and East Africa. It connects **service seekers** (people who need work done) with **service providers** (skilled professionals) across 19 service categories.

### What You Can Do

- **Find Service Providers** — Browse verified professionals for house help, plumbing, electrical work, tutoring, and more.
- **Post Jobs** — Create listings to hire someone for a specific task or ongoing work.
- **Apply for Work** — Service providers can browse and apply to available jobs.
- **Communicate** — Message service providers or clients directly through the in-app chat.
- **Review & Rate** — Leave reviews after a job is completed to help others make informed decisions.

### Who Is It For?

| User Type | Examples |
|-----------|---------|
| **Service Seekers** | Homeowners, tenants, families, businesses looking to hire |
| **Service Providers** | House helps, plumbers, electricians, tutors, painters, mechanics, etc. |

## 3. Authentication

Huduma Platform uses **phone-number-based authentication** with OTP (One-Time Password) verification via SMS. No password is required.

### Step 1: Onboarding

When you first open the app, you will see a three-page introduction:

- **Page 1 — Find Trusted Services:** Learn about finding verified professionals near you.
- **Page 2 — Housing Made Easy:** Discover rental and housing options.
- **Page 3 — Verified & Reviewed:** Understand how reviews and verification work.

Swipe left/right to navigate between pages, then tap one of:
- **"Get Started"** — To create a new account.
- **"I already have an account"** — To sign in.

Both options proceed to the phone entry screen.

### Step 2: Enter Your Phone Number

1. Your country code defaults to **Kenya (+254)**.
2. Enter your **10-digit phone number** (e.g., 0796287215).
3. Tap **"Continue"**.

### Step 3: Verify OTP

1. A **6-digit verification code** will be sent to your phone via SMS.
2. Enter the code in the input field.
3. The code **auto-submits** when all 6 digits are entered.
4. If you did not receive the code, wait for the **60-second timer** to expire, then tap **"Resend Code"**.

After successful verification, you will be directed to the **Home Screen**.

> **Note:** If this is your first time, you may be asked to set up your profile before proceeding (see Section 11).

## 7. Creating a Listing

### How to Create a Listing

1. Tap **"Post a Job"** on the Home Screen, or navigate to the Create Listing screen.
2. Fill in the form:

| Field | Required | Description |
|-------|----------|-------------|
| **Listing Type** | Yes | Choose "Hire Someone" or "Request Service" |
| **Title** | Yes | Descriptive title (minimum 10 characters) |
| **Category** | Yes | Select from the dropdown of 19 categories |
| **Description** | Yes | Detailed description (20–1000 characters) |
| **Budget Min** | No | Minimum budget in KES |
| **Budget Max** | No | Maximum budget in KES |
| **Budget Period** | No | Monthly, weekly, daily, or one-time |
| **Location** | No | County or area where the work is needed |
| **Engagement Type** | No | One-time, ongoing, or contract |

3. Tap **"Create Listing"** to publish.
4. A success message will appear and you will be returned to the previous screen.

### Tips for a Good Listing

- Use a clear, specific title (e.g., "Need experienced plumber for kitchen sink repair in Westlands").
- Write a detailed description including scope of work, requirements, and timeline.
- Set a realistic budget range to attract qualified providers.
- Specify the location to help providers assess commute distance.

## 8. Applying to a Listing

### How to Apply

1. Open a listing and tap the **"Apply"** button.
2. An application form appears with:

| Field | Required | Description |
|-------|----------|-------------|
| **Cover Message** | No | Brief message to the poster (max 500 characters) |
| **Proposed Rate** | No | Your proposed rate in KES |

3. Tap **"Submit Application"** to send.
4. A confirmation message will appear.

### Tips for Applications

- Write a personalized cover message highlighting your relevant experience.
- Propose a competitive rate that reflects the job scope.
- Be responsive — check your messages after applying as the poster may reach out.

## 13. Reviews & Ratings

### How Reviews Work

After a job is completed, both parties can leave reviews:

| Component | Description |
|-----------|-------------|
| **Rating** | 1 to 5 stars |
| **Comment** | Written feedback about the experience |

### Viewing Reviews

- Reviews appear on user profiles and listing detail screens.
- Your **average rating** is calculated from all reviews received and displayed on your profile.

### Leaving a Review

1. Navigate to the completed listing.
2. Tap the review option.
3. Select a star rating (1–5).
4. Write an optional comment.
5. Submit your review.

> **Note:** Reviews are permanent and cannot be edited or deleted. Please be honest and constructive.

## 15. Troubleshooting

### Common Issues

| Problem | Solution |
|---------|----------|
| **OTP not received** | Wait 60 seconds and tap "Resend Code". Check that your phone number is correct. Ensure you have SMS reception. |
| **App won't load** | Check your internet connection. Try closing and reopening the app. |
| **Cannot submit application** | Ensure you are logged in. Check that the listing is still active. |
| **Profile not updating** | Ensure all required fields (First Name, Last Name) are filled. Check your internet connection. |
| **Messages not sending** | Check your internet connection. The app uses real-time WebSocket — a stable connection is required. |
| **Listing not appearing** | New listings may take a moment to appear. Pull down to refresh the listings page. |

### Contact Support

If you experience issues not covered above, use the **Help & Support** option in your Profile screen.

## System Architecture Overview (for Administrators)

| Component | Technology | Purpose |
|-----------|-----------|---------|
| Mobile App | Flutter (Dart) | Cross-platform user interface |
| Backend API | NestJS (TypeScript) | Business logic, authentication, data management |
| Database | PostgreSQL (Neon) | Persistent data storage |
| Cache | Redis (Upstash) | Session management, OTP storage |
| Authentication | JWT + OTP via SMS | Secure phone-based login |
| Real-time | WebSocket (Socket.IO) | Instant messaging |
| SMS Provider | Africa's Talking | OTP delivery |

### API Base URL

```
https://your-railway-domain.up.railway.app/api/v1
```

### Key API Endpoints

| Endpoint | Method | Description |
|----------|--------|-------------|
| `/auth/otp/request` | POST | Request OTP for phone number |
| `/auth/otp/verify` | POST | Verify OTP and get JWT token |
| `/auth/refresh` | POST | Refresh expired JWT token |
| `/profiles` | GET/PUT | View or update profile |
| `/categories` | GET | List all service categories |
| `/listings` | GET/POST | Browse or create listings |
| `/listings/:id` | GET | View listing details |
| `/applications` | GET/POST | View or submit applications |
| `/reviews` | GET/POST | View or submit reviews |
| `/chat/conversations` | GET | List conversations |
| `/chat/conversations/:id/messages` | GET | Get messages in conversation |
| `/notifications` | GET | View notifications |
